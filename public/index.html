TFDiagram

Paste Terraform code or a GitHub repo URL (AWS or Azure) and get an architecture diagram.

Finds public repositories on GitHub. Press Draw diagram on a result to open it here. Use GitHub's search words too, like org:hashicorp or user:name.

The zip is opened in your browser. Only the text of the .tf files is sent to be analysed; nothing is stored.
